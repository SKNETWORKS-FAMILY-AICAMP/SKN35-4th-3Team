# 실패 질문 18개 원본·전처리·검색 대조

기존 43개 중 14개와 추가 15개 중 4개를 분석했다. 지정 근거와 실제 검색 청크를 구분하며, 정답·점수·코드·데이터는 변경하지 않았다.

## 확인 결과

- 지정된 근거는 18개 질문 모두에 존재한다. 세부 조건까지 충분히 답하는지는 별도로 검토했다.
- 지정 근거 원본 6개 문서와 대체 후보 자료를 재추출해 저장본과 대조했으며 불일치는 없었다.
- 모든 검색 대상의 청크 본문·위치·누락 검사와 원본·보완 PDF 해시 검사를 통과했다.
- 자동 재현성 통과와 의미상 좋은 청킹은 별개다. 아래의 페이지 문맥·팝업·적용 범위 문제를 확인했다.

| 검색 단계에서 지정 근거가 밀린 위치 | 질문 수 |
|---|---:|
| 재순위화 100개 밖 | 5 |
| 문서당 2개 제한 | 7 |
| 최종 5위 밖 | 5 |
| 300개 후보에도 미포함 | 1 |

## 우선 작업

1. 데이터: 쇼핑 안내 29~30페이지의 청약철회 방해문구라는 문맥을 이어 보존한다. 잘못된 판매자 문구를 유효한 규칙으로 사용하지 않도록 인용 역할을 구분한다.
2. 데이터: 소비자원 일반 접수 안내와 특정 업체·기간 한정 팝업을 DOM 기준으로 분리한다.
3. 데이터: PDF의 Q&A·장 제목·판결 날짜를 구분하고, 해고예고 원칙과 예외가 함께 전달되는지 확인한다.
4. RAG: 법령 전체에 적용되는 문서당 2개 제한으로 밀린 7개 질문을 별도 실험한다. 단순 후보 수 확대와 구분해야 한다.
5. RAG: 후보 절삭 6개와 낮은 순위 5개를 분리해 개선한다. 컷오프만 늘리면 점수가 오를 것이라고 단정하지 않는다.
6. 평가·수집: 대체 근거는 원문 조건을 검토한 후 정답 후보로 논의한다. 문자·입금 내역 질문은 더 구체적인 공식 근거가 필요하다.
